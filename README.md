# John Tiempo portfolio

A personal portfolio for John Carlo Tiempo, known professionally as John. Civil engineering, commercial construction, custom software, AI automation, and e-commerce experience.

## Run locally

Serve this directory with any static HTTP server and open the address it prints. No installation or build is required.

## Publish on GitHub Pages

Publish the `main` branch from the root directory in repository Settings, Pages. The application uses relative asset paths and supports both user and project Pages URLs.

## Update content

- `index.html`: main page, experience, contact details, and featured projects.
- `app.js`: project index and case-study details.
- `style.css`: typography, colors, layout, and responsive rules.
- `assets/mark.svg`: favicon.

The page works without a build tool. Fonts are requested from Google Fonts, with local fallbacks. No analytics, accounts, tracking scripts, or backend services are included. The copy-email action requires browser clipboard permission; an actionable fallback is displayed if unavailable. The experience selector switches between engineering/construction and automation/e-commerce timelines.
